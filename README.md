# prelegal

Platform for drafting common legal agreements.

## Status

🚧 **Work in progress.** This project is under active development and is targeted for
completion by **16 August 2026** (one week from 9 August 2026).

The repository currently contains only project scaffolding — setup, usage, and
project-structure documentation will be added as the implementation lands. Expect
breaking changes until the first release.
